# AI Code Review Assistant

AI Code Review Assistant is a GitHub-focused project for reviewing code changes with AI support. The repository is organized with a frontend application and supporting project code for building an assisted code review workflow.

## Repository Structure

- `frontend/` - Frontend application for the review assistant interface.
- `ai-code-review-assistant/` - Supporting application code and project files.

## Getting Started

Clone the repository and install the dependencies for the part of the project you want to run.

```bash
git clone https://github.com/Nikk6174/ai-code-review-assistant.git
cd ai-code-review-assistant
```

Refer to the README files or setup instructions inside each project area for local development commands.
